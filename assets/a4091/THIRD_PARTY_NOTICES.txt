A4091 v42.39 ROM - component inventory and third-party notices
================================================================

Bundled file
------------

File: a4091_cdfs.rom
Upstream release: https://github.com/A4091/a4091-software/releases/tag/v42.39
Upstream release asset:
https://github.com/A4091/a4091-software/releases/download/v42.39/a4091_cdfs.rom
Upstream source commit: ce6d62cf2db5c6bf990e4d675d633f2dedcc84a6
SHA-256: 01ab100153e2faf2bc653e57e27db1672ceca81dd7c3d1c0b6d63ebe58dbe24b

This is an unmodified upstream release artifact. The v42.39 source repository
does not contain one project-wide LICENSE file and does not declare the whole
ROM to be GPL-licensed. Its build and source tree identify the following
components in a4091_cdfs.rom:

1. The A4091 AutoConfig ROM bootstrap and relocator, with a compressed
   a4091.device built from the A4091 project sources. The driver includes
   NetBSD/Berkeley/OSF-derived SCSI code and the mounter listed below.
2. The mounter from the A4091/mounter submodule at
   48c8c1cfdcda37fb9d4d6fd7b1bfd8f789402c1a.
3. The ODFileSystem ROM profile from the reinauer/ODFileSystem submodule at
   9afca352dc1cc27950b5d8d00bbaf5fb3edfb2e2. That profile enables ISO 9660,
   Rock Ridge, Joliet, and multisession support and disables UDF, HFS, HFS+,
   and CDDA.
4. The 68000 ZX0 decompressor from reinauer/salvador at
   bf562ffec873a72ee324beb4358fa680121e5852.

The notices below are reproduced from those exact source revisions.
