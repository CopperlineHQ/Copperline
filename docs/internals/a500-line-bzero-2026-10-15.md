## Observer correction found during review

The earlier kinds 25–27 use BLTCPT=$11000 and BLTDPT=$10000. In line
mode, later D writes follow the updated C pointer. Their OR scan of
$10000–$107fe and words $10000/$10050/$100a0 therefore observe the initial
D region, not all later line writes. Those checked words match across the
captures, but this does not establish that every generated line pixel is
zero or that all later destination words agree. The kind-28 observer must
scan both regions and sample $11050/$110a0 before flag semantics are inferred.

## Shift and history controls

Kind 33 repeats the zero-B, `$ca`, one/two-pixel test across all 16 A
and B shifts, with and without B DMA (1,024 rows). A second hardware run
of the identical ROM differs in only two BZERO observations; beams and all
sampled memory agree. One-pixel cases keep BZERO set. Two-pixel cases
produce an irregular shift-dependent pattern that the universal `$ffff`
intermediate-B hypothesis cannot explain. These are effective `A & B` masks,
not independently measured B shifter words. The earlier A/C-stage experiment
only establishes its rule for the particular A shifts tested.

Kind 34 adds four preconditions to a 1,024-row subset: no priming, a normal
B-data register write, and normal two-word B+D copies using zero and `$ffff`
data. All four produce nearly the same line BZERO patterns. Normal shifter
history alone is therefore insufficient to explain the residual. Kind 34
source ID is `07aa9a9c91bef61cf337e3b4bbf2c23d807504b8a77b0c3664acf86bcee385b8`;
hardware packet SHA-256 is
`c55347b0ae74d0d12b57f6169f874c937ceee2572f434640e71df5218a56bb37`.

## Excluded draft captures

The first kind-31/32 texture archives had a generator error: their table
contained the raw B shift index instead of the literal BLTCON1 register word.
Those ROMs alternated line/normal mode rather than varying the intended line
B shift. Their hardware and emulator captures are preserved for provenance
but excluded from all hardware conclusions. Corrected v2 ROMs encode
`(BSH << 12) | 1`; a new test decodes every generated table row against its
manifest. All 47 probe Python tests pass. Hardware comparisons must identify
the corrected source IDs, rather than relying on a kind number alone.

### Equal-cycle opcode control, kind 35

The A500 completed 1,920 rows with zero timeouts/skips and a valid checksum.
